📋 第 1 题：资讯系统架构与企业运作层级深度分析
满分 10分
📌 【情境材料】
某大型跨国连锁零售集团“环球乐购”正在对其核心资讯系统进行现代化升级重构。该集团的日常业务运作涵盖三大不同层次的人员与管理职责：
- 层次甲（基层运作层）：涵盖全马 120 家实体分店的数千名收银员与仓储理货员，每天发生数百万笔商品条码扫描、实时移动支付与库存即时扣减；
- 层次乙（中层管理层）：涵盖各区域门市经理与供应链主管，需要每周调阅各类别生鲜食品的库存周转率、门市销售额环比变动报表，并据此调整下周的采购配额；
- 层次丙（高层决策层）：涵盖集团总裁（CEO）与董事会成员，需要结合未来三年东南亚宏观经济走势、竞争对手扩张情报以及集团五年财务战略，评估是否在东马投资设立自动化物流中心。
问题：
  1. 1. 请分别写出针对层次甲、层次乙、层次丙最相匹配的资讯系统类型英文简称与全称。（3分）
  2. 2. 简述层次甲所对应的资讯系统在系统工程设计上必须具备的两个关键技术特征。（2分）
  3. 3. 假设该集团电商平台在“双十一”购物节迎来并发流量峰值（瞬时请求量达到平时的 50 倍）。若要确保系统不崩溃且交易数据零丢失，请从系统架构设计角度提出三种主流的高并发优化策略并简述其实现原理。（3分）
  4. 4. 在资讯系统规划过程中，该集团面临“自研定制开发”（Custom Development）与“采购现成商用软件包”（Commercial Off-The-Shelf, COTS）两种选择。请分别从开发周期与业务贴合度两个维度，各指出一项两者的对比优劣。（2分）
🎯 官方参考答案要点与阶梯采分点
🎯 官方标准参考答案
1. 系统类型对应（3分，各1分）：
• 层次甲（基层运作层）：TPS（Transaction Processing System / 交易处理系统 / 事务处理系统）；
• 层次乙（中层管理层）：MIS（Management Information System / 管理资讯系统）；
• 层次丙（高层决策层）：EIS / ESS（Executive Information System / Executive Support System / 主管资讯系统 / 主管支援系统）。
2. 层次甲系统（TPS）的两大关键技术特征（2分，各1分）：
• 高并发实时性与极高吞吐量：能够毫秒级处理海量日常并发事务，响应迅速；
• 数据一致性与原子性（ACID 原则）：确保每一笔库存扣减与交易记录要么完全成功，要么完全回滚，严防错账、重复扣款与脏读。
3. 高并发三大主流优化策略及原理（3分，各1分）：
• 策略一：负载均衡与横向水平扩展（Load Balancing & Horizontal Scaling）：通过 Nginx 或硬件负载均衡器将巨量用户流量分发至多个无状态应用伺服器节点，消除单点瓶颈；
• 策略二：引入分布式缓存（如 Redis Cache）与读写分离：将频繁查询的商品详情与热点数据预热缓存在内存中，90% 以上的读请求直接由缓存响应，数据库只负责核心写操作，大幅减轻数据库压力；
• 策略三：异步消息队列削峰（Message Queue，如 Kafka/RabbitMQ）：将高并发的下单排队请求先推入消息队列，应用后台按照系统处理能力平滑消费，避免瞬时海量洪峰直接冲垮底层交易数据库。
4. 自研开发 vs 采购商用现成软件（COTS）对比（2分，各1分）：
• 开发周期：COTS 现成软件安装部署快，可在极短时间内上线投产；自研定制开发需要经历完整的 SDLC 周期，耗时较长；
• 业务贴合度：自研开发能够完全贴合该集团独特的业务流程与个性化管理规则；COTS 软件通常通用性强，企业往往需要被迫调整自身业务逻辑去迎合软件标准，或额外支付高昂的二次定制费用。

📋 第 2 题：数据流程图（DFD）分析与业务逻辑建模
满分 10分
📌 【情境材料】
某独中图书馆计划开发一套全新的“图书线上借阅与智能催还系统”。该系统的初步业务调研情况如下：
- 外部参与者：包含“学生/教职员（读者）”以及“图书馆管理员”；
- 借书流程：读者在终端扫描学生卡并录入图书条码，系统中的【验证借阅资格】程序会查询【读者档案数据仓】，核验该读者是否已有逾期未还图书或欠款。若资格合法，程序将借阅请求转发给【执行借出登记】程序，该程序会同时更新【图书库存数据仓】中的在馆状态，并在【借阅记录数据仓】中新增一条带有应还日期的借阅条目，最后向读者打印出借凭条；
- 催还流程：系统中的【逾期排查与通知】程序每天午夜自动扫描【借阅记录数据仓】，若发现图书超过借阅期限仍未归还，则向该读者的校园邮箱自动发送催还邮件，同时向“图书馆管理员”生成每日逾期未还统计报表。
问题：
  1. 1. 在结构化系统分析方法中，数据流程图（DFD）通常采用哪四种基本建模图元？请写出其图元名称并注明其各自代表的含义。（4分）
  2. 2. 根据上述业务描述，请准确列出本系统中的：
    - 所有的外部实体（External Entities）；（2分）
    - 所有的数据储存/数据仓（Data Stores）；（2分）
  3. 3. 在绘制 DFD 时，存在若干严格的语法规范（如守恒原则与黑洞/奇迹现象）。请指出下列两种画法是否合规，并简述理由：（2分）
    - 画法 A：在【读者档案数据仓】与【图书库存数据仓】之间直接用一条带箭头的单向数据流连接；
    - 画法 B：一个名为【借阅统计】的程序只有若干条数据流流入，但没有任何数据流流出该程序。
🎯 官方参考答案要点与阶梯采分点
🎯 官方标准参考答案
1. DFD 四种基本建模图元及含义（4分，各1分）：
• 数据流（Data Flow）：带有箭头和描述名称的连线，表示数据在系统各部件之间的流动方向与数据包内容；
• 处理 / 程序（Process）：通常用圆圈或圆角矩形表示，代表系统内部对数据执行的变换、加工、计算或业务操作；
• 数据储存 / 数据仓（Data Store）：开口矩形或平行线段，表示系统内部用于保存数据的静止载体（如数据库表或物理文件）；
• 外部实体（External Entity）：双实线方框，表示存在于系统边界之外、与系统发生数据输入或输出交互的人员、部门或其他外部系统。
2. 本系统的外部实体与数据储存归纳（4分，各2分）：
• 外部实体（2分）：① 学生/教职员（读者）；② 图书馆管理员。（各1分）
• 数据储存 / 数据仓（2分）：① 读者档案数据仓；② 图书库存数据仓；③ 借阅记录数据仓。（答全给2分，缺一扣1分）
3. 两种画法合规性判定与理由（2分，各1分）：
• 画法 A 判定：不合规（错误）（0.5分）。理由：DFD 语法严禁在两个数据储存（Data Store）之间直接连线流动。数据从一个数据仓转移到另一个数据仓，必须经过某个具体的“处理/程序”来进行读取与写入转换（0.5分）。
• 画法 B 判定：不合规（错误）（0.5分）。理由：此现象在 DFD 建模中称为“黑洞”（Black Hole）。一个合法的处理程序必须有输入也有输出；若仅有数据流入而没有任何数据流出，说明该处理没有产生任何业务价值，违反了 DFD 的数据守恒法则（0.5分）。
📊 官方细目评分量规与阶梯采分标准
评分维度优秀（Full / 9-10分）良好（Good / 7-8分）基础（Basic / 4-6分）待改进（Poor / 0-3分）
四种建模图元（4分）准确列出数据流、处理、数据仓、外部实体并精炼阐明业务含义。列出 4 种名称，但含义解释有 1 处模糊。仅答出 2-3 种图元名称，概念有所混淆。完全混淆了流程图（Flowchart）与 DFD。
实体与数据仓提取（4分）外部实体（2个）与数据仓（3个）完全从材料中精准提取，无遗漏。提取了大部分，遗漏了 1 个数据仓。误将内部处理（如验证资格）当做外部实体。实体与数据仓概念混为一谈。
语法规则判定（2分）准确判定两者均违规，并指出“仓与仓不能直连”及“黑洞现象”。判定正确，但无法准确说出“黑洞”或程序守恒原理。仅判定出一处合规性。误认为两种画法均可被系统接受。
📋 第 3 题：网络拓扑设计、性能计算与协议分层应用
满分 10分
📌 【情境材料】
某独中新建了一座 4 层楼的“科技资讯大楼”，每层楼设有 2 间大型电脑机房，每间机房配备 40 台学生用计算机。
学校向电信运营商申请了一条对称的独享千兆光纤宽频接入（带宽标称：1 Gbps）。
网络拓扑架构设计如下：每间机房各配置一台 48 端口千兆接入交换机，大楼核心机房配置一台三层核心交换机与一台企业级硬件防火墙/路由器。
问题：
  1. 1. 针对每间电脑机房内部的计算机物理互联，最适合采用哪种物理网络拓扑结构（Topology）？请写出拓扑名称并列举该拓扑的两大核心技术优点。（3分）
  2. 2. 多媒体网络传输计算题：
    机房教师需要通过局域网向 40 台学生机同时分发一段大小为 750 MB 的教学高清视频文件。
    假设每台学生机与交换机之间的实际平均可用下载速度为 100 Mbps（兆比特每秒）。
    请严格写出单位转换与推导步骤，计算单台学生机理论上下载完成该视频所需的最少时间（单位：秒，保留至整数）。（3分）
  3. 3. 学生在浏览器地址栏输入校内教学资源平台网址 http://moodle.school.edu.my 并按下回车后，电脑顺利打开了网页。请写出在此过程中依次参与工作的四个核心网络协议的英文缩写，并简述各协议在此过程中的具体职能。（4分）
🎯 官方参考答案要点与阶梯采分点
🎯 官方标准参考答案
1. 机房拓扑结构与技术优点（3分）：
• 拓扑名称：星状拓扑（Star Topology）（1分）；
• 两大核心优点（2分，各1分）
① 易于故障诊断与隔离：单台计算机或连接网线发生物理损坏，仅影响该节点自身，绝对不会导致整个机房网络瘫痪；
② 扩展与维护极方便：增加、移动或拆除电脑只需在中心交换机上插拔网线，无需中断其他正常教学设备的网络连接。
2. 多媒体网络传输计算题推导（3分）：
• 步骤一：将文件容量转换为总位元数（Bits）：（1分）

750 MB = 750 × 1024 × 1024 Bytes × 8 bits = 6,291,456,000 bits

（注：若采用商业十进制标准 750 × 10⁶ × 8 = 6,000,000,000 bits 亦算合理）；

• 步骤二：转换传输速率单位：（1分）

100 Mbps = 100 × 10⁶ bps = 100,000,000 bits/s；

• 步骤三：计算理论传输时间：（1分）

T = (6,291,456,000 bits ÷ 100,000,000 bits/s) ≈ 62.91 秒 ≈ 63 秒

（若按十进制标准计算：T = (6,000,000,000 ÷ 100,000,000) = 60 秒。两者结果均给予满分）。

答：单台学生机理论上下载完成所需的最少时间约为 63 秒（或 60 秒）。

3. 四个核心网络协议及职能（4分，各1分）：
① DNS（域名系统协议）：将人类易读的域名 moodle.school.edu.my 转换解析为计算机可识别的目标伺服器 IP 地址；
② TCP（传输控制协议）：在学生机与校内 Web 伺服器之间通过“三次握手”建立可靠的端到端虚拟连接，确保网页数据可靠传输；
③ HTTP / HTTPS（超文本传输协议）：应用层协议，用于客户端浏览器向伺服器发送网页资源的 GET 请求，并接收返回的 HTML/CSS 内容；
④ IP（网际协议）/ ARP（地址解析协议）：负责将数据分割为 IP 数据包并进行网络寻址与路由选择（若答 ARP 负责解析局域网网关 MAC 地址亦同等满分）。

评分维度优秀（Full / 9-10分）良好（Good / 7-8分）基础（Basic / 4-6分）待改进（Poor / 0-3分）
拓扑选型与优点（3分）选定星状拓扑，并精准从单点容错与维护扩展两个维度总结优点。选定星状拓扑，优点描述略偏日常口语。拓扑选型正确但无法讲清中心交换机的隔离作用。错答成总线拓扑或环状拓扑。
网络传输计算（3分）严格呈现“容量 → 字节 → 位元 → 除以速率”三步法，答案精准。步骤清晰，但末尾保留整数或单位换算出现微小进位笔误（扣1分）。混淆了 Byte 与 bit 的 8 倍关系（如漏乘 8）。公式完全错误，胡乱拼凑数字。

📋 第 4 题：资讯安全综合防御方案与黑客渗透应对
满分 10分
📌 【情境材料】
2026年下半年，某私立独立中学遭遇了一次严重的网络安全勒索事件：
周一清晨，学校教务处的核心教务伺服器被发现所有学生学籍成绩与财务收费数据全部被后缀为 .locked 的高强度加密算法锁定，桌面留有一封勒索信要求支付 5 个比特币方可提供解密私钥。
经过校方技术顾问团队排查，还原了黑客的入侵路径：
  1. 1. 第一步：黑客伪装成教育局督学向多位教务处职员发送名为“2026独中课程评估最新标准.docx”的带毒宏邮件，一名职员点击运行后，计算机被植入特洛伊木马；
  2. 2. 第二步：黑客通过该受控终端在内网嗅探，发现教务伺服器的远程桌面协议（RDP 3389端口）暴露且管理员密码竟是极为脆弱的 Admin@123456；
  3. 3. 第三步：黑客暴力破解后横向渗透登入伺服器，不仅加密了本地数据库，还将挂载在同一局域网共享盘上的每日自动备份文件一并加密破坏。
    问题：
  4. 1. 结合黑客入侵的第一步，指出该职员遭遇了哪种具体的社会工程学攻击类型？学校应建立哪两项针对教职员工的日常资讯安全管理防范规范？（3分）
  5. 2. 结合黑客入侵的第二步，请针对伺服器的远程访问管理与凭证策略，提出两项立竿见影的技术加固措施。（2分）
  6. 3. 针对第三步中“本地备份与局域网网络备份全军覆没”的惨痛教训，资讯安全领域推崇著名的“3-2-1 备份原则”。请完整阐述 3-2-1 备份原则的具体内涵。（3分）
  7. 4. 从现代网络安全防御理念出发，“防火墙与杀毒软件已无法保证 100% 绝对不被渗透”。请简述何谓“纵深防御”（Defense in Depth）策略，并说明其核心思想。（2分）

🎯 官方标准参考答案
1. 社工攻击类型与日常管理防范（3分）：
• 具体攻击类型：鱼叉式网络钓鱼（Spear Phishing） 或 恶意电子邮件附件宏病毒攻击（1分）；
• 两项日常管理防范规范（2分，各1分）
① 严禁开启不明外部来源附件与未知宏代码：组织全员网络安全意识培训，对陌生公文邮件保持警惕，办公软件默认禁用宏执行；
② 落实多渠道离线交叉核实机制：凡涉及敏感课纲调整、财务款项或账密重置的公文邮件，必须通过电话或当面与发件人再次确认。
2. 两项立竿见影的技术加固措施（2分，各1分）：
① 修改默认远程端口并结合 VPN 访问：禁用或更改公网默认的 RDP 3389 端口，强制要求必须先通过内网 VPN 认证才允许发起远程连接；
② 强制启用多因素认证（MFA）与强密码及防爆破锁定策略：彻底废止弱口令，启用“数字密码＋动态令牌”认证，并配置在连续输错 5 次密码后自动锁定账户 30 分钟。
3. “3-2-1 备份原则”的具体内涵（3分，各1分）：
• 3：重要核心业务数据必须持有 3 份完整副本（1 份原始生产数据 ＋ 2 份备份副本）；
• 2：备份数据应存放在 2 种不同的物理存储介质上（例如：本地磁盘阵列 NAS ＋ 磁带/外部可移动硬盘）；
• 1：必须保证有 1 份副本存放在异地（Off-site）或物理隔离（Air-gapped 离线网络断开）环境中，以抵御火灾、地震以及局域网全盘勒索加密。
4. “纵深防御”（Defense in Depth）策略及核心思想（2分）：
• 策略内涵：纵深防御是指不在单一防线上投入所有希望，而是设置多道不同层次的安全控制防线（包括物理层安全、网络边界防火墙、主机访问控制、应用层过滤、数据强加密与员工安全意识）（1分）；
• 核心思想：承认“任何单一防御措施均有被突破的可能”。当黑客攻破外层边界防火墙后，后续的主机加固、内网隔离、权限最小化及数据加密机制依然能够有效阻止其横向扩散与数据窃取，从而最大化降低攻击造成的灾难性后果（1分）。
