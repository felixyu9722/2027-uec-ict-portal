📋 第 1 题：数据流图（DFD）分析、分层规范与黑洞排查
满分 10 分
📌 【情境材料】
某独中科技处正在开发一套“智慧校园课外活动选课与学分认定系统”。
业务流程梳理如下：
- 外部实体：包含“学生”、“社团指导教师”与“教务主任”；
- 选课业务：每学期初，【发布可选社团清单】程序从【社团课程档案仓】中读取本学期开放的所有社团名单与名额上限；学生在前端登录后提交选课意愿，【核验选课资格与名额】程序会查询【学生学籍数据仓】与【选课记录数据仓】，若名额未满且学生无冲突选课，则由【确认选课登记】程序更新【选课记录数据仓】并在【社团课程档案仓】中扣减一个可用名额，最后向学生发出“选课成功确认回执”；
- 考核业务：学期末，指导教师提交学生平时出勤与考核成绩，【成绩登记与学分核算】程序核算后将学分写入【学生学籍数据仓】，并向“教务主任”打印汇总全校社团成绩分析报表。
问题：
  1. 1. 结合上述情境，请完整写出本系统的：
    - 所有的外部实体（External Entities）；（3分）
    - 所有的数据储存 / 数据仓（Data Stores）。（3分）
  2. 2. 在绘制数据流图（DFD）时，必须严格遵守语法规范。请指出下列两种画法是否存在逻辑错误，并简述理由：（2分）
    - 情形 A：一个名为【社团名额统计】的处理（Process）有多条来自不同数据仓的数据流输入，但没有任何一条数据流流出该处理；
    - 情形 B：在【社团课程档案仓】与【选课记录数据仓】之间，直接画了一条带双向箭头的单条数据流连线。
  3. 3. 简述在系统分析中，绘制“0 阶数据流图（Diagram 0 / Level 0 DFD）”相较于“环境图（Context Diagram / 顶层图）”的最主要区别是什么？（2分）

2. DFD 语法错误判定与理由（2分，各1分）：
• 情形 A 判定：存在逻辑错误（不合规）（0.5分）。理由：此现象在 DFD 规范中称为“黑洞”（Black Hole）。一个合法的处理（Process）必须有输入也有输出，只有输入而没有任何输出意味着该处理没有产生任何业务价值，违反了数据守恒原则（0.5分）；
• 情形 B 判定：存在逻辑错误（不合规）（0.5分）。理由：DFD 语法严禁在两个数据储存（Data Store）之间直接连线流动。数据从一个数据仓转移到另一个数据仓，必须经过某个具体的“处理/程序”来进行读取与转换加工（0.5分）。
3. 0 阶 DFD 与环境图的核心区别（2分）：
• 环境图（Context Diagram / 顶层图）：将整个资讯系统视为一个单一的顶层处理圆圈（编号为 0），仅展现系统与外部实体之间的高层数据输入与输出交互，不展示系统内部的任何子程序与数据储存（1分）；
• 0 阶图（Diagram 0 / Level 0 DFD）：对顶层系统进行第一次逻辑分解，展现系统内部的核心主要子处理程序（如 1.0、2.0、3.0）、主要数据储存（数据仓）以及子处理之间流转的详细数据流（1分）。

1.2 GB = 1.2 × 1024 × 1024 × 1024 Bytes × 8 bits ≈ 10,307,921,510 bits

   WHERE Student.class_name = 'Senior3A'
   GROUP BY Student.student_id, Student.name
   HAVING SUM(Scholarship_Award.amount) >= 1000.00
   ORDER BY 累计奖学金总额 DESC;

📋 第 5 题：现代网络安全全方位防御实战与企业级纵深防御体系
满分 10 分
📌 【情境材料】
某独立中学搭建的面向全马招生的“高一新生在线报到与缴费系统”在开放报名的首日遭遇了严重的网络安全攻击：
- 攻击现象 1：清晨 8:00 报名开启瞬间，系统遭受到来自全球数百个外部 IP 的海量伪造 SYN 握手包冲击，带宽被打满，服务器 CPU 负载飙升至 100%，正常家长无法打开网站；
- 攻击现象 2：上午 10:00，黑客利用自动化脚本扫描，在报名查询界面的身份证号输入框中提交了精心构造的 SQL 注入攻击载荷，企图拖取后台包含数千名新生敏感家庭住址与银行卡信息的数据库。
问题：
  1. 1. 针对攻击现象 1：指出该攻击的专业网络安全术语名称是什么？学校若要从网络架构层面迅速缓解该攻击以保障正常家长访问，可采取哪两项主流技术方案？（3分）
  2. 2. 针对攻击现象 2：指出该攻击的攻击类型，并简述网站后端软件开发团队在编写数据库交互代码时，彻底根治该安全漏洞的核心编程防御规范。（2分）
  3. 3. 在保障网络传输机密性与防篡改方面，学校必须为该缴费网站全面启用 HTTPS 协议。
    请简述浏览器在与服务器建立 HTTPS 安全会话时，由权威证书颁发机构（CA）签发的数字证书在其中发挥的核心安全认证作用。（2分）
  4. 4. 从信息安全管理与“纵深防御”（Defense in Depth）理念出发，学校在防范内外部网络安全威胁时，应建立怎样的多层防御纵深架构？请列举覆盖“网络边界、主机终端、数据存储与人员素养”四个维度的具体管理与技术防护措施。（3分）

🎯 官方标准参考答案
1. DDoS 攻击名称与架构缓解方案（3分）：
• 专业术语：SYN Flood（SYN 洪水攻击） 或 分布式拒绝服务攻击（DDoS）（1分）；
• 两项缓解方案（2分，各1分）
① 引入云端抗 D 高防服务（如 Cloudflare / 运营商高防清洗中心）：利用云端海量带宽在网络边缘清洗过滤恶意 SYN 伪造流量，仅将合法请求回源到学校服务器；
② 在边界防火墙或服务器启用 SYN Cookie 机制与连接限速：阻止未完成三次握手的半连接占满操作系统内核 TCP 连接队列（Backlog）。
2. SQL 注入攻击与核心编程防御规范（2分）：
• 攻击类型：SQL 注入攻击（SQL Injection）（1分）；
• 核心编程防御规范：后端开发必须彻底摒弃通过字符串拼接构造 SQL 的不良做法，全面强制采用参数化查询（Parameterized Queries）与预编译语句（Prepared Statements），使传入的用户输入仅作为普通参数常量处理，绝不被数据库引擎当作可执行指令解析（1分）。
3. CA 数字证书的核心安全认证作用（2分）：
• 防伪与身份认证：由受信任的权威 CA 机构对学校网站的公钥及所有者身份信息进行数字签名，浏览器利用内置的受信任根证书验证该签名，从而确保证书真实可信，彻底挫败假冒钓鱼网站与中间人拦截伪造公钥的企图（2分）。
4. 全方位“纵深防御”四维度防护措施（3分）：
① 网络边界层：部署硬件下一代防火墙与入侵防御系统（IPS），阻断非法端口扫描与 DDoS 洪水；
② 主机终端层：开启自动打补丁，安装终端杀毒防护软件（EDR），并强制通过组策略禁用宏代码执行；
③ 数据存储层：落实高强度 AES-256 全盘加密与基于 3-2-1 原则的物理隔离（Air-Gapped）离线冷备份；
④ 人员素养层：开展全员反钓鱼社会工程学防范培训，推行强密码策略与多因素身份认证（MFA）。
