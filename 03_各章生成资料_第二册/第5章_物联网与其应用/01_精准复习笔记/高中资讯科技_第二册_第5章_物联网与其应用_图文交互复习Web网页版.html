🌐 5.1 物联网简介与三大技术架构

物联网的权威内涵与三层架构深度解析

📌 董总考纲官方标准定义：什么是物联网 (IoT)？

物联网（Internet of Things, IoT） 是由物理世界中各种物体组成的网络。它通过各种传感设备、软体和网络通信技术，将物理实体与互联网相连接，进行双向通信与数据交换，以实现智能化的识别、定位、追踪、监控和管理。

人与人 ➔ 物与物 (M2M) 演进 物理实体全面数字化映射 感知-传输-智能决策闭环
TOP LAYER

应用处理层 (Application Layer)

系统的“大脑与四肢”

结合云计算、大数据、人工智能与中央控制台，对汇集上海量模拟信号进行处理、决策分析，并向现场设备发出指令动作。

代表应用：智慧家居App、智能交通配时中枢、无人超市结算系统、智慧农场云平台
MIDDLE LAYER

网络传输层 (Network Layer)

系统的“神经脉络”

利用互联网、无线蜂窝网络或局域通信协议，将感知层采集的数据安全、快速、低延时地汇总传输至远端服务器或云端。

代表协议：Wi-Fi、蓝牙 BLE、ZigBee、LoRa、NB-IoT、4G/5G 蜂窝、光纤以太网
BOTTOM LAYER

感知层 (Perception Layer)

系统的“五官与触觉”

位于物理最底层，利用各种传感器 (Sensor)、RFID 标签和音视频采集器，捕获现实物理世界的环境变化、状态参数并转为电信号。

代表组件：温湿度计、被动红外 (PIR)、RFID 标签、陀螺仪、摄像头、电机执行器

🔬 感知层基石

传感器 (Sensor) 与执行器 (Actuator) 运作原理全谱系

传感器（Sensor） 是一种检测装置，能感受到被测量的信息，并能将感受到的信息按一定规律变换成为电信号或其他所需形式的信息输出，以满足信息的传输、处理、存储、显示、记录和控制要求。

💡 重点概念辨析：传感器 (Sensor) 与 执行器 (Actuator) 的本质区别

传感器 (Input) 负责“从物理世界捕获信息转换为数字世界信号”；而 执行器 (Output) 负责“接收系统数字控制指令并转化为现实物理动作”，例如开启自动水阀、驱动步进电动机、合上继电器或点亮警告警笛。

📡 网络通信选型

RFID 射频识别与短距无线通信技术矩阵对比

🏷️ 射频识别系统 (RFID) 核心三要素

  • 电子标签 (Tag)： 由耦合元件及芯片组成，每个标签具有唯一电子编码 (UID)。分为无源与有源两类。
  • 读写器 (Reader)： 发射特定射频电磁波并接收标签反向散射信号，读取或改写标签存储数据。
  • 射频天线 (Antenna)： 在标签与读写器之间传递射频电磁信号，完成能量供给与射频数据收发。

⚡ 有源标签 (Active) vs 无源标签 (Passive)

  • 无源标签 (Passive)： 无内置电池，完全依靠读写器发射的电磁波感应取电，体积极小、成本廉价、寿命理论无限（图书借还、超市服装防盗标签）。
  • 有源标签 (Active)： 内置锂电池，主动发射射频信号，识别距离远（可达几十米至数百米），成本高、电池寿命有限（高速公路电子不停车收费 ETC、集装箱实时监控）。

🏠 5.2 典型应用实战

智能家居系统的四大核心组件与情景自动化闭环

01

中央控制网关 (Smart Hub)

智能家居的心脏与决策枢纽，负责协议转换（将 ZigBee/BLE 转为 Wi-Fi/以太网），本地执行自动化规则引擎。

02

环境与安防传感器 (Sensors)

负责持续感知室内物理参数，如门窗开合磁敏传感器、温湿度传感器、人体移动传感器、燃气漏气探头。

03

智能执行器与末端设备 (Actuators)

接收系统指令改变物理状态的电气设备，如智能插座、电动窗帘电机、智能冷暖空调、智慧电子门锁。

04

用户交互界面 (User Interface / App)

人类用户监控并下达指令的载体，包括手机移动端 App、智能音箱语音助手（如 Siri/小爱同学）、智能墙壁触摸中控屏。

智慧城市、精准农业与无人便利店高阶综合实战

🌱 智慧农业 (Precision Farming)

在农田布设土壤水分、光照度、酸碱度 (pH) 传感器。当监测到土壤相对含水量低于 30% 且光照强烈时，云端自动触发电磁水阀执行水肥一体化动态微喷灌；达到标准含水量后自动闭阀，节水率达 40% 以上。

🚦 智慧城市与智能交通 (Smart City)

智慧路灯根据环境光强度与车流红外传感器自适应调节照度；路口地磁车辆检测器将实时通行拥堵数据上传至交警指挥中枢，动态调整红绿灯配时时长，缓解交通拥堵瓶颈。

🛒 高层次统考思维题：无人便利店（无感零售）四大核心红利

无人便利店依托“计算机视觉 + RFID 射频识别 + 货架压力传感器 + 智能移动支付”多模态感知与边缘计算协同运行，为现代商业带来颠覆性价值：

1. 极致无感体验： 拿了就走 (Just Walk Out)，无需排队人工扫码买单，极大节省顾客购物结算耗时。
2. 削减人力开支： 门店无需收银员与大量导购，实现 7×24 小时全天候低运营成本自主营业。
3. 实时精准库存： 货架重量传感器与 RFID 瞬时感知货品余量，自动向供应链云端发出缺货补货预警，消灭盘点盲区。
4. 沉淀消费画像： 实时追踪顾客行走动线、拿起放回热力图，为精准营销与热卖选品提供大数据支撑。

🛡️ 安全纵深防御

物联网重大安全风险、攻击形态与纵深防御策略

⚠️ 物联网固有脆弱性根源

  • 硬件资源高度受限： MCU 算力弱、内存极小，无法运行复杂的高强度非对称加密算法（如 4096-bit RSA）。
  • 出厂默认弱口令： 海量智能摄像头、家用路由器出厂普遍使用 admin/123456 等硬编码密码且用户很少更改。
  • 固件更新机制缺失： 大量低成本设备缺乏 OTA 安全空中升级通道，已知漏洞多年无法修补。
  • 物理暴露于户外： 农田、路灯传感节点部署在无防御公共场所，容易被物理拆解提取密钥。

🛡️ 统考标准纵深防御应对举措

  • 强密码认证与防暴力破解： 强制设备初次配置时更改默认口令，采用多因素认证或数字证书认证。
  • 网络隔离与虚拟局域网 (VLAN)： 将 IoT 智能设备独立划分至隔离的 Guest 或 IoT VLAN，阻断其向核心办公/内网主机的横向渗透。
  • 轻量级端到端加密： 采用针对物联网定制的轻量级加密协议（如 AES-128、TLS/DTLS），保障回传数据机密性与完整性。
  • 固件签名空中安全更新 (OTA)： 保证固件带有私钥签名校验，防止被刷入恶意劫持的恶意代码。
🚨 统考经典高频易错题警示：Mirai 僵尸网络警示录

2016年震惊全球的 Mirai 僵尸网络 正是利用全球数十万台出厂未修改默认密码的网络摄像头、数码录像机 (DVR) 实施横向快速感染，并向核心 DNS 服务商 Dyn 发起峰值超过 1 Tbps 的巨量 DDoS 洪水攻击，造成全美半数互联网陷入瘫痪。这深刻印证了：“每个安全链条中最脆弱的物联网小节点，都可能成为击溃整体关键基础设施的跳板！”

- 网络层（网络逻辑微隔离）（2 分）：在医院核心交换机与路由器上划分独立的“医疗物联网专属虚拟局域网（Medical IoT VLAN）”，将所有联网监护仪、输液泵与病区访客公共 Wi-Fi 以及普通办公外网实施完全的逻辑网络隔离；并在网关边界部署下一代防火墙（NGFW），配置严格的访问控制列表（ACL），坚决禁止任何从外部公网或访客 Wi-Fi 网段向医疗物联网设备的跨网段主动连接。
- 感知层 / 设备端（固件及接入鉴权硬化）（2 分）：对所有联网监护仪与输液泵实施固件安全硬化，在系统底层彻底关闭所有未使用的调试通信端口与明文服务（如禁用 Telnet、FTP、未加密 HTTP）；强制在首次入网时修改出厂默认密码为高复杂度唯一密钥，并在硬件内部引入安全芯片（Secure Element）实现安全启动（Secure Boot）与基于 IEEE 802.1X 端口接入证书双向认证，杜绝伪造非法设备伪装接入。
