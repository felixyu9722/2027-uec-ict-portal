🛡️ 三、 6.1 资讯安全风险和防范 (Information Security Risks and Defense)

(1) 企业级资讯安全防御五大核心举措（课本核心问答题）

🖼️ [全景幻灯 02/12] 企业级资讯安全防御五大核心举措体系 🔍 点击全屏放大

董总新课本与官方参考答案为现代企业信息安全建设制定了标准五维体系：

  1. 员工培训 (Staff Training)：定期对全体员工进行资讯安全意识和技能培训，提升资讯素养，强化对资讯伦理与操作风险的认知，构筑“人脑防火墙”；
  2. 遵守操作规范 (Compliance with Standard Procedures)：员工在日常业务中必须严格遵从企业制定的安全操作程序与权限规程，最大限度消弭人为失误给系统带来的安全威胁；
  3. 安全运作政策 (Secure Operational Policies)：企业管理层必须建立严谨、完备的安全管理制度（如最小权限原则、强密码定期更换规则），压缩系统漏洞与黑客入侵空间；
  4. 定期备份和还原 (Regular Backup & Recovery)：落实自动化、异地化数据备份机制，制定灾难应急恢复预案，确保在遭遇系统崩溃或黑客勒索时能够迅速还原重要数据；
  5. 专人侦测 (Professional Security Assessment)：聘请专业外部资讯安全顾问机构，定期对企业网络拓扑、服务器漏洞、员工行为与业务流程进行渗透测试与安全评估，防患于未然。

(2) 获取软硬件漏洞信息的四大渠道（课本重点问答题）

🖼️ [全景幻灯 03/12] 获取软硬件安全漏洞信息的权威渠道 🔍 点击全屏放大

面对日新月异的技术漏洞，使用者应通过多维渠道保持敏锐感知：

  1. 关注官方最新公告：密切关注软硬件原厂（如 Microsoft, Apple, Google）发布的更新通告、补丁说明（Patch Notes）或安全警报；
  2. 参考其他用户社区反馈：浏览技术论坛、社交媒体专区或开发者社区，关注其他先行用户遇到的突发 Bug 与异常反馈；
  3. 依赖专业安全机构考证：查阅国家计算机网络应急技术处理协调中心、权威杀毒安全公司发布的专业漏洞安全评估报告；
  4. 自我日常观察与性能检测：在使用过程中，敏锐察觉电脑发热异常、网络流量激增、不明后台进程等异常征兆，运用基础知识自查。

(3) 个人数字金融与密码安全五大金律（学生生活防身必备）

🖼️ [全景幻灯 04/12] 个人数字金融与账户密码安全五大金律 🔍 点击全屏放大
  1. 拒绝个人信息弱密码：严禁使用出生日期、电话号码、纯姓名拼音作为密码，应采用包含大小写字母、数字与特殊字符的长复杂密码；
  2. 强制开启双重验证 (2FA)：即使密码被撞库窃取，攻击者没有用户手机上的动态短信或验证器 OTP 码依然无法登入；
  3. 设定电子钱包单日交易限额：对 Touch 'n Go eWallet, GrabPay 等移动支付设定合理的单笔与单日额度，阻断巨额盗刷；
  4. 谨慎绑定实体银行卡：非刚需尽量避免电子钱包长期绑定主银行账户或大额信用卡，降低连带金融穿透风险；
  5. 慎重扫描未知二维码：街头小广告、来历不明传单上的二维码极易植入恶意木马或跳转至仿冒钓鱼网站，切忌盲目扫码。

(4) 公共电脑设备与数据安全备份准则

🖼️ [全景幻灯 05/12] 公共设备使用与数据安全备份黄金准则 🔍 点击全屏放大
  • 公共电脑使用安全四规范（如网吧、机场打印店、图书馆电脑）：
    • ① 必须使用浏览器的无痕式窗口（Incognito / Private Mode）；
    • ② 离开前必须彻底清除浏览器历史记录、Cookie 与临时下载文件；
    • ③ 严禁在公共电脑上进行任何网络银行登录、账号密码修改与网络支付操作；
    • ④ 随时注意物理周围环境，防范他人身后窥探偷看密码（Shoulder Surfing）。
  • 数据备份黄金准则：落实定期备份、多介质异构存储（移动硬盘 + 外部存储），并实施云端异地灾备。

⚖️ 四、 6.2 资讯社会责任 (Information Social Responsibility)

(1) 资讯伦理 (Ethics) vs 资讯素养 (Literacy) 的本质辨析（统考必考概念）

🖼️ [全景幻灯 06/12] 资讯伦理 (Ethics) vs 资讯素养 (Literacy) 本质辨析 🔍 点击全屏放大

董总课本给出了权威定义与边界划分：

  • 资讯伦理 (Information Ethics)：
    • 定义：人们在应用网络和资讯系统时应当遵守的道德准则与行为规范。
    • 核心指向：回答“什么该做，什么不该做”，关乎良知、守法、尊重他人隐私与知识产权。
  • 资讯素养 (Information Literacy)：
    • 定义：使用者高效管理与驾驭资讯的综合实践技能 (Skills)。
    • 四大能力维度：
      1. 确认所需资讯的目标与范围；
      2. 获取多元资讯的能力（传统文献与网络资源）；
      3. 评估资讯真伪、时效性与权威度的能力；
      4. 应用资讯的能力（合规引用版权、融会贯通与创造性产出）。

(2) 知识产权 (Intellectual Property) 法律保障的深远意义

🖼️ [全景幻灯 07/12] 知识产权法律保障与版权合规常识 🔍 点击全屏放大

如果知识产权得不到有效法律保障，将对社会文明造成灾难性打击：

  1. 原创者合法权益受损：盗版与抄袭导致创作者无法收回研发成本与智力劳动报酬，生存艰难；
  2. 社会创作与创新活力衰退：当心血作品得不到保护与尊重，将极大挫伤创作者的创作热情，导致新学术思想、新文化作品与新技术产出锐减，最终抑制整个国家与社会的文化繁荣与科技进步。

(3) 经典恶意软件深度剖析：WannaCry 勒索病毒事件复盘（课本高频案例）

🖼️ [全景幻灯 08/12] 恶意软件深度剖析：WannaCry 勒索病毒事件复盘 🔍 点击全屏放大
  • 病毒属性与传播机制：属于典型的勒索软体 (Ransomware)，融合了蠕虫 (Worm) 的主动网络自传播特性；利用了 Windows 系统（如 Windows XP, Server 2003）底层 SMB 漏洞入侵，迅速加密电脑所有文件并同网传染。
  • 勒索机制：袭击者通过暗网 Tor 匿名浏览器与受害者联系，强制要求受害者以比特币 (Bitcoin) 支付巨额赎金换取解密密钥。
  • ⚠️ 防范铁律：坚决不鼓励受害者支付赎金！原因有二：
    1. 即使支付了赎金，犯罪分子也绝不保证会真的返还解密密钥；
    2. 支付赎金实质上是在资助网络犯罪，将极大助长此类勒索袭击的犯罪歪风！

(4) 应对网络霸凌 (Cyberbullying) 的标准处置程序与冷暴力反思

🖼️ [全景幻灯 09/12] 应对网络霸凌 (Cyberbullying) 标准处置程序 🔍 点击全屏放大
  1. 不回应：不参与网络对骂与唇枪舌战，切断施暴者的心理快感；
  2. 截取证据：完整截屏保存聊天记录、恶意评论、对方账号信息与时间戳；
  3. 向师长求助：及时向父母、班主任或学校辅导老师坦诚倾诉，寻求心理支援与干预；
  4. 报警备案：当涉及人身安全恐吓或严重名誉侵害时，果断报警依法追究。

⚠️ 旁观者的冷暴力警示：许多旁观者因害怕引火烧身而保持沉默，这种沉默实质上是对施暴者的纵容，是一种极其残忍的冷暴力；它会给受害者造成沉重的二度心理创伤，并导致校园与网络戾气恶性循环。

(5) 公共 Wi-Fi 钓鱼陷阱深度解析：中间人攻击防范

🖼️ [全景幻灯 10/12] 公共 Wi-Fi 钓鱼陷阱深度还原与中间人防范 🔍 点击全屏放大

黑客常在公共场所架设同名的仿冒钓鱼热点（Evil Twin），诱使顾客连接并借助中间人监听窃取明文账户密码。防范三对策：① 向店家核准真实 SSID；② 优先使用个人蜂窝移动数据；③ 严禁在公共开放 Wi-Fi 下进行金融登录与转账支付。
