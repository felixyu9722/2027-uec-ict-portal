📌 作答题 1 · 电脑解决问题的阶段（12分） ▼
研究人员需要设计一套程式，用于根据用电时数（T小时）计算电费。已知：0到30小时免费；31至40小时按每小时RM0.50计算；超过40小时部分按每小时RM1.00计算（另加前10小时超额费RM5.00）。
a设计用虚拟码（Pseudocode）表达该程序的演算法，处理所有分段电费的计算逻辑。
b为该程序绘制标准流程图 (Flowchart)，需包含判断框与正确的分支逻辑。
📋 参考答案
a) 虚拟码 (6分)
开始
输入 用电时数 T
若 T ≤ 0 则 输出 "错误：用电时数不能为0或负数！" 结束
若 T ≤ 30 则：超额时数 = 0，电费 = 0.00
否则若 T ≤ 40 则：超额时数 = T - 30，电费 = 超额时数 × 0.50
否则：超额时数 = T - 30，电费 = 10 × 0.50 + (超额时数 - 10) × 1.00
输出 "超额时数:"，超额时数
输出 "电费:"，电费
结束
b) 流程图要点 (6分)
① 起止框："开始"
② 输入框：输入用电时数 T
③ 判断框："T ≤ 0？" → True：输出错误信息，结束；False：继续
④ 判断框："T ≤ 30？" → True：电费=0；False：继续
⑤ 判断框："T ≤ 40？" → True：超额费=0.5×(T-30)；False：超额费=5.0+(T-40)×1.0
⑥ 输出框：输出电费结果
⑦ 起止框："结束"
📊 评分量规
a) 每个正确分段逻辑条件各2分，共6分。b) 起止框1分+输入框1分+每个判断框1分（共3分）+输出框1分=6分。
📌 作答题 2 · Python 搜寻代码追踪（12分） ▼
以下 Python 代码使用 For 循环与 If-Else 统计偶数的总和与个数：
Total = 0; Count = 0
for i in range(1, 11):
  if i % 2 == 0:
    Total = Total + i
    Count = Count + 1
print(Total, Count)
a用追踪表（Trace Table）追踪程式的执行过程，记录每次循环后 i、Total、Count 的值变化。（每正确填写一行得2分，共8分）
b程式最终输出 Total 和 Count 的值各为多少？（各2分）
📋 参考答案
a) 追踪表 (8分)
i=2：Total=2, Count=1 ✓（偶数）
i=4：Total=6, Count=2 ✓（偶数）
i=6：Total=12, Count=3 ✓（偶数）
i=8：Total=20, Count=4 ✓（偶数）
i=10：Total=30, Count=5 ✓（偶数）
奇数 i（1,3,5,7,9）不执行累加，Total/Count 不变。
b) 输出结果 (4分)
Total = 30（2+4+6+8+10 = 30）（2分）
Count = 5（1~10 之间共5个偶数）（2分）
📊 评分量规
a) 每行追踪正确得2分，共4行×2=8分。b) Total正确2分，Count正确2分。
📌 作答题 3 · 冒泡排序追踪（12分） ▼
原始数组（降序冒泡）：[18, 56, 34, 92, 27]

📋 参考答案
a) 贪进法定义与应用 (6分)
定义（2分）：贪进法是在面临多重选择时，每步选择局部最优（成本最小或收益最大）的策略，以期解决问题，效率高但不一定全局最优。
找零过程（4分）：
剩余 RM1.80 → 选 RM1.00（最大面额）→ 剩余 RM0.80

📌 模拟题 5 · 贪进法 vs 暴力法情境辨析（12分） ▼
旅行商问题：商人要拜访5个城市（A、B、C、D、E），每两城市间距离已知，要求找出总距离最短的路线。
a若用暴力法解决5城市问题，最多需要考虑多少种路线？（提示：排列数 = (N-1)! / 2）（4分）
b若用贪进法解决（每次前往最近未访问城市），描述从A出发的选择过程（假设：AB=10,AC=25,AD=15,AE=20；BD=8,BE=12...）并说明贪进法的局限性。（8分）
📋 参考答案
a) 暴力法路线数 (4分)
N=5城市，从固定起点出发，其余4城市全排列数 = 4! = 24种路线
若路线无向，则路线数 = 4!/2 = 12种（往返视为同路）
暴力法需检验所有 12种 路线，取最短者。（4分）
b) 贪进法过程与局限 (8分)
贪进法过程（4分）：
从A出发 → 最近未访城市是B(AB=10) → 从B出发 → 最近未访是D(BD=8) → 从D出发 → 选E或C...
每步选局部最短距离，快速得到一条路线。
局限性（4分）：
①贪进法只保证局部最优，不一定是全局最短路线。可能因为早期的"近"选择导致后续路程反而更长。
②对旅行商问题，暴力法才能保证找到真正最短路线（虽然当N很大时极慢）。

a) 排列数计算2分+正确结论2分=4分。b) 贪进法步骤描述4分+局限性分析（局部vs全局1分+说明1分+暴力法对比2分）=8分。
